# Adding an entry

A retraction entry is a finished argument, not a confession. It needs four parts and a number.

## Template

```markdown
# NNN — "<the belief, in the words we held it>"

**Believed:** <from> → <until> · **Killed:** <date> · **Status:** <corrected in place | tests now pin the intent | atlas row rewritten | ...>

## What we believed
One paragraph. The belief strong enough that we acted on it.

## Why it seemed true
One paragraph. Steelman the past self — the evidence that made the belief reasonable at the time.

## What killed it
The artifact: a benchmark table, an issue link, a 404, a code line, a maintainer's resolution. Link it.

## What changed
Bulleted. The edits, the rules adopted, the tests added. A retraction without a change is just an apology.
```

## Rules

- Number sequentially, zero-padded (`006-...`). Gaps are forbidden; a withdrawn entry keeps its number and gains a note.
- Name the belief, never the person.
- The killing artifact must be public or quotable. "We realized" is not an artifact.
- If the original public artifact still exists, edit it with a visible correction note and link both directions.
