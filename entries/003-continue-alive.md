# 003 — "Continue is an active project"

**Believed:** until 2026-10-05 · **Killed:** 2026-10-05 · **Status:** atlas row rewritten

## What we believed

Continue (continuedev/continue, ~36k stars) belongs in a capability atlas as a live harness, researched like the others.

## Why it seemed true

Star count, name recognition, and a docs domain that existed in every prior mention of the project. Popularity is a terrible liveness proxy and we used it anyway.

## What killed it

During the atlas v2 research run: the repo is **read-only**, the docs home (`continue.dev/docs/intro`) returns **404**, Hub pages are dead, and the last release (v2.0.0) is the final one. The researcher's evidence URLs for "active" claims were gravestones.

## What changed

- The atlas row for Continue now carries its end-of-life in `limitations`, and its capability cells still report what the final release *does* support — including a quietly shipped Claude Code-compatible hooks engine and SKILL.md loading, which is precisely the kind of fact a dead project can still teach.
- Atlas rule added (CONTRIBUTING §4): discontinued is data. Rows for dead projects stay, dated, because they document where the compatibility surfaces ended up.
